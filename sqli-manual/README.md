# SQL手工注入Less-1到Less-22学习笔记

## 项目简介

本文件夹收录sqli-labs中Less-1到Less-22 全部关卡的手工SQL注入完整学习笔记。全程分析闭合方式、构造Payload、验证漏洞，用于夯实SQL注入底层原理，脱离工具依赖，掌握注入核心思维。

覆盖：GET注入、POST注入、报错注入、布尔盲注、时间盲注、User-Agent注入、Referer注入、Cookie注入、Base64编码注入等全部主流注入场景。

## 学习目标
- 掌握不同引号、括号的SQL语句闭合逻辑
- 熟练手写 UNION 查询、报错、布尔、延时四类Payload
- 理解 HTTP 请求不同位置注入（URL、表单、请求头、Cookie）
- 掌握编码绕过、注释符绕过、无注释闭合技巧
- 建立从源码分析 → 闭合判断 → 构造Payload → 拿数据的完整注入思路

## 文件夹内容说明
- 各关卡独立笔记：每关包含源码分析、闭合方式、漏洞原理、分步Payload、实操截图、个人思考与理解
- 注入分类总结：报错注入、盲注、头注入、Cookie编码注入
- Payload手写模板：库名/表名/字段/数据查询通用语句

## 核心知识点汇总
1. 闭合类型区分
- 数字型：无引号，直接拼接
- 字符型单引号：`'`闭合
- 字符型双引号：`"`闭合
- 单引号+括号：`')`闭合
- 双引号+括号：`")`闭合
  
2. 四大手工注入类型
- Union联合注入：有回显，直接查询数据
- 报错注入：无回显、有报错，利用updatexml/extractvalue爆数据
- 布尔盲注：页面对错回显不同，逐字符猜解数据
- 时间延时盲注：无回显无报错，依靠sleep延时判断

3. 特殊注入场景
- UA注入、Referer注入（请求头注入）
- Cookie明文注入
- Cookie Base64编码注入（关键：先解码再拼接SQL）

## 学习总结
手工注入是SQL注入的根基，本套笔记完整走完所有基础场景，彻底理解：注入本质就是破坏原有SQL语句结构、自定义拼接恶意语句。所有工具注入原理均来自手工逻辑，熟练手工后可快速理解并掌握SQLMap自动化原理。
